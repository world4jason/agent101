# Readability Flow PR

## Learner narrative

這版不按名詞排課，改成一條專案因果鏈：

```text
定義問題
→ 定義完成（AC / Example）
→ Issue 保存工作契約
→ Kanban 顯示狀態
→ Agent 執行並用 PR 交付
→ Preview / Evidence 提供可驗證成果
→ Human Acceptance
→ Merge / Production
```

## Editorial rules

- 開場總覽與最後收束可以重述主旨，其餘每頁必須新增一個理解或決策。
- 同一概念定義一次；後面只引用或應用。
- 初階在 Production 後明確結束，進階工具不回頭干擾主流程。
- 不把 PR 與 Evidence Pack 拆成兩次相同的交付說明。
- 不把 Requirement template 拆成獨立字典頁。
- 不把 Skill / MCP / RAG / Plugin 各自拆成 glossary 頁，改成同一張能力地圖。

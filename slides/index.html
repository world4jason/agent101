給非工程背景的人

你不需要會做，
但要能定義什麼叫做好。

Agent 101 不是工具名詞課。它是一套把想法變成可委派、可追蹤、可驗收工作的流程。

先破除誤解
AI 不是許願池，是需要被委派與驗收的 worker。
你定義問題→AI 協助釐清→AI 執行→人類驗收
課程分層
初階講流程；進階才講工具系統。

Agent 101｜外行人主線

需求、AC、Issue、Kanban、PR、Preview、驗收、上線。

Agent 201｜大量使用 Agent 後

Skill、Subagent、Context、MCP、RAG、Plugin、SDD、BMAD。

Agent 101 主流程
先把工作講清楚，再讓 AI 開始做。
想法我想改善什麼？
需求誰、問題、範圍、限制。
AC怎樣才算完成？
執行Issue、Kanban、Agent、PR。
驗收Preview、Evidence、Approve。
Requirement
需求不是「我要一個功能」，而是「我要解決一個情境裡的問題」。

不夠

幫我把搜尋做好一點。

比較好

手機使用者現在只能一直滑；這次先做標題關鍵字搜尋，不做推薦與模糊搜尋。

Requirement Template
外行人只要先會問六個問題。
  • 為什麼做？
  • 誰要用？
  • 現在卡在哪？
  • 這次要做什麼？
  • 這次不要做什麼？
  • 怎樣算成功？
Acceptance Criteria
AC 要在開工前寫，因為它決定你怎麼驗收。

不要寫

手機版要正常。

改成

390px 寬度下不出現水平捲軸；CTA 完整可見；主要文字不重疊。

Examples / BDD
不要問 AI「你懂吧」；給它一個可以重現的例子。

在什麼情況？
未登入。

做什麼？
按下收藏。

應該看到什麼？
要求登入，不顯示收藏成功。

Issue
Issue 是工作契約，不是一句待辦。
Goal：為什麼做
Scope / Non-goals：做什麼、不做什麼
AC / Examples：怎麼判斷完成
Evidence：完成後要交什麼證據
Kanban
Agent 說 Done，只代表可以進 Review。
Backlog→Ready→In Progress→Review→Done
PR
PR 是交付包，不只是工程師看的 code diff。
AGENT
做了什麼對應哪張 IssueAC 完成狀態
REVIEWER
打開 Preview對照 ACApprove / Request Changes
驗收流程
非技術人員不需要看懂 code，仍然可以驗收成果。
有東西PR / Preview / Evidence
檢查過Build / Test / Security
符合 AC自己操作核心情境
真的有用產品判斷
才上線Merge / Production
Evidence Pack
不要相信一句 Done；要求可以獨立檢查的證據。
  • Preview URL：我可以自己操作
  • AC Checklist：每條 Pass / Fail
  • Before / After：UI 改了什麼
  • Automated Checks：基本檢查是否通過
  • Known Limitations：還有哪些風險
練習
你會 approve 嗎？
AC 寫著：「未登入按收藏要要求登入。」
Agent 只回：「已完成。」沒有 Preview、沒有截圖、沒有測試結果。
答案：Request Changes。沒有可驗證成果，就不能進 Done。
Deployment
上線是最後一步，不是 Agent 完成後自動發生的事。
PR→Preview→Human Acceptance→Merge→Production
進階地圖
工具名詞很多，但它們回答的是不同問題。
怎麼做？Skill
誰來做？Subagent
去哪找？Search / RAG
怎麼連？MCP / Plugin
怎麼管？GitHub / Kanban / PR
怎麼放大？SDD / BMAD / Superpowers
Skill / Plugin / MCP / RAG
Skill 是 know-how；MCP 和 Plugin 是連接；RAG 是找知識。
Skill：教 AI 這類工作怎麼做。
Plugin：把你的 App / 帳號接進 ChatGPT。
MCP：外部工具與資料的共同連接標準。
RAG：先取回相關資料，再讓模型回答。
Context
不要追求永遠不忘記的 Agent；建立忘記也能接手的系統。
Spec+Issue+PR+Evidence
Method Map
BDD、TDD、SDD、BMAD 不在同一層。
BDD對齊行為
TDD建立 feedback loop
SDD先定義 spec
BMAD交付作業系統
GitHub留下狀態與證據
最後帶走
普通人和 AI 合作，最重要的不是會下指令。
是把模糊想法，變成可以委派、追蹤、驗收的工作。
